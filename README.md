# Untitled Preset Launcher

App that allows you to define presets of apps and folders that get opened on the press of a shortcut.

## Functionality

Presets allow opening:
- Apps
- Files (.pdf, .docx, .txt)
- Browsers with a URL (i.e., a browser opening with Claude already open )

Allow user to define time delay between each app/file open to account for slower hardware.
